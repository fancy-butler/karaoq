    ✅ Pre-party check

    Run this when you set up, before guests arrive. Green = good to go. Anything else tells you what to do.

    🎤 Microphones

    Plug mics into this computer's sound card (or a USB mic) and they play through the speakers with the song, with reverb and echo. The host can also change all of this from their phone: ☰ → 🎤 Mics.

    ReverbEchoAll mics
    Speakers

    Tip: several mics on one interface (Mbox, UR44, Audio Kontrol…)? Pick the same device for each and choose which input each mic is on — e.g. Mic 1 = input 2, Mic 2 = input 5, Mic 3 = input 6. Quiet mic? Turn up the gain knob on the interface first (phantom power/+48 V doesn't make a dynamic mic louder), then its slider here. If singers hear themselves late, use your interface's direct-monitor knob for the dry voice and keep reverb/echo here.

    💾 Karaoke library

    Got a hard drive of karaoke files? Point KARAO-Q at the folder and those songs show up in everyone's search, marked 💾. Works with CD+G (.cdg + .mp3, loose or zipped) and karaoke videos (.mp4, .mkv, .avi…). Each song is converted the first time it's queued — a second or two.
